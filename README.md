# Arcade Megamania

Jogo completo de tiro espacial (shmup) de tela fixa inspirado no classico "Megamania" do Atari 2600, desenvolvido em um unico arquivo HTML usando HTML5 Canvas e JavaScript puro (sem bibliotecas externas e sem arquivos de midia).

## Caracteristicas
- Resolucao interna: 320x240 pixels (4:3), com escalonamento inteiro pixel-art.
- Graficos 8-bit desenhados via codigo (matrizes de pixels).
- Efeitos sonoros sintetizados em tempo real com a Web Audio API.
- Fonte bitmap em pixel art renderizada diretamente no canvas.
- Barra de energia dinamica com duracao de 30 segundos.
- Ciclo de 5 tipos de inimigos classicos:
  1. Hamburgueres voadores
  2. Bolachas/biscoitos
  3. Ferros de passar roupa
  4. Gravatas-borboleta
  5. Diamantes
- Controles para teclado (Setas / A e D / Espaco) e suporte a dispositivos moveis (botoes virtuais na tela e controle por toque/arraste).

## Como Executar
Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).
